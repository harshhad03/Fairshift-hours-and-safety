# FairShift: Fair hours. Transparent pay. Safer workplaces.

A web app built for UN SDG 8 (Decent Work & Economic Growth).

## What it does

**Worker Portal**
- Check in / check out with a live shift timer
- Weekly hours chart and a transparent payslip showing exactly how net pay is calculated
- "Check your pay": compare the amount received with the payslip and report a discrepancy
- Report safety issues, with an option to submit anonymously

**Employer Dashboard**
- Workforce overview: total workers, on shift now, overtime, open reports
- Workload alerts when someone exceeds an adjustable weekly hours limit
- Attendance table, safety reports and pay issues with status tracking (Submitted, Under Review, Action Taken, Resolved)

Includes two sample workplaces: a Construction Company and a Hospital.

## Demo limitations

This is a prototype. All data is sample data stored in the browser (localStorage), so it does not sync across devices and does not provide real anonymity. A production version would need a real database, authentication and server-side privacy controls.
